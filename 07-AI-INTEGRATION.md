# AI Integration

## AI Responsibilities
- Explain issue
- Explain likely cause
- Explain impact
- Suggest fix
- Answer follow-up questions

## Expected Output

```json
{
  "problem": "",
  "cause": "",
  "impact": "",
  "suggestedFix": ""
}
```

## Reliability
- Keep original evidence.
- Do not present assumptions as confirmed facts.
- Use "likely cause" when root cause is not proven.
- Prefer structured JSON responses.
