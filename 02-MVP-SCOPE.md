# MVP Scope

## Must Build
- Chrome Extension using Manifest V3
- Popup UI
- Inspect Page button
- Active tab information
- Content script communication
- URL and page title collection
- Images and alt attributes
- Links, buttons and forms
- Missing title detection
- Missing image alt detection
- Empty link detection
- Empty button detection
- Basic form accessibility checks
- Issue severity
- Deterministic health score
- Issue details
- Problem, Cause, Impact and Suggested Fix
- AI explanation or follow-up

## Optional
- Screenshot
- Console errors
- Network errors
- Responsive checks
- Lighthouse
- axe-core

## Out of Scope
- Screenshot-to-code
- GitHub integration
- Repository analysis
- Automatic code fixes
- Pull request generation
- Continuous monitoring
- Billing
