# Project Overview

## Product
Origami Lens is an AI-powered website inspection tool starting with a Chrome Extension.

## Product Promise
**Problem → Cause → Impact → Suggested Fix**

## Tuesday Deliverable
A working MVP that can inspect a real webpage, detect issues, calculate a health score, and display explanations and suggested fixes.

## Architecture Principle
Browser Evidence → Deterministic Analysis → Issue Normalization → AI Reasoning → Results

AI explains findings. Browser evidence and rules establish facts.
